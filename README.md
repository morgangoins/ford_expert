# ford_expert

python script to scrape all new vehicles from fordfairfield.com

How to run it? "python scrape.py"

more specifically, the url is https://www.fordfairfield.com/new-inventory/index.htm

working!!

pulls VIN,Year,Make,Model,Trim,Exterior Color,Interior Color,Odometer,MSRP,Stock Number,Fuel Economy
